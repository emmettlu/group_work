# 增强版 Samba 远程命令执行漏洞（CVE-2017-7494）

[English version](README.md)

## 🎯 挑战概述

这是经典 SambaCry 漏洞挑战的**增强复杂版**。原始漏洞太简单了 - 只需要运行 exploit.py 就能获取 root 权限。这个版本添加了多层复杂性、误导和真实的企业安全措施，创造了更具吸引力的 CTF 体验。

## 🔍 新增特性

### 增强复杂性特性：
1. **多层基础设施** - Web 应用、数据库、安全监控、SSH 蜜罐
2. **真实企业环境** - 多个服务，复杂网络拓扑
3. **误导与虚假安全** - 假安全头部、误导版本信息
4. **多种攻击向量** - SQL 注入、文件上传漏洞、信息泄露
5. **安全监控模拟** - 假 IDS/IPS 警报迷惑攻击者
6. **复杂认证** - 多个用户账户，不同权限级别

## 🎭 服务详情

### 1. Samba 文件服务器（目标）
- **IP**: 容器 IP（用 `docker inspect` 查看）
- **端口**: 445, 139
- **版本**: 4.6.3（有漏洞）但报告为 4.6.4
- **共享**: 多个不同访问级别的共享

### 2. Web 应用（诱饵和攻击向量）
- **URL**: http://localhost:8080
- **特性**: 
  - SQL 注入漏洞
  - 有缺陷的文件上传
  - 假安全监控
  - 多用户账户

### 3. 数据库服务器
- **端口**: 3306
- **凭据**: 查看 docker-compose.yml
- **包含**: 用户数据、系统配置、假日志

### 4. 安全监控仪表板
- **URL**: http://localhost:8081
- **用途**: 显示假安全警报误导攻击者

### 5. SSH 蜜罐
- **端口**: 2222
- **用途**: 捕获 SSH 暴力破解尝试

## 🕵️ 攻击方法论

### 阶段 1：侦察
```bash
# 端口扫描（要隐蔽避免"检测"）
nmap -sS -p- target_ip

# 服务枚举
nmap -sV -p 445,139,8080,3306,8081,2222 target_ip

# Web 应用发现
dirb http://target:8080
nikto -h http://target:8080
```

### 阶段 2：Web 应用分析
1. **检查登录页面**: http://target:8080/
2. **测试 SQL 注入**: 在登录表单尝试 `' OR '1'='1`
3. **探索文件上传**: http://target:8080/fileupload.php
4. **搜索用户**: http://target:8080/search.php
5. **检查管理面板**: http://target:8080/admin.php

### 阶段 3：信息收集
```bash
# 连接到 Samba 共享
smbclient -L //target_ip -N
smbclient //target_ip/public -N
smbclient //target_ip/private -U sambauser

# 检查可读共享
smbclient //target_ip/secure -U admin
```

### 阶段 4：漏洞开发
1. **找到真正漏洞**: 尽管有各种误导，CVE-2017-7494 仍然有效
2. **识别正确共享**: 并非所有共享都同样脆弱
3. **确定物理路径**: 使用 Web 应用和文件列表的信息
4. **制作漏洞利用**: 为这个特定环境创建或修改漏洞利用

### 阶段 5：漏洞利用
```bash
# 方法 1：直接 Samba 漏洞利用（经典）
./exploit.py -t target_ip -e malicious.so -s SHARENAME -r /physical/path/malicious.so

# 方法 2：Web 应用到文件上传到 Samba
# 1. 通过 Web 应用上传恶意文件
# 2. 找到文件位置
# 3. 使用 Samba 执行它
```

## 🧩 关键挑战

### 1. 信息过载
- 运行多个服务
- 假安全警报
- 误导版本信息
- 复杂网络拓扑

### 2. 虚假安全指标
- "安全级别：高" 头部
- 假漏洞扫描结果
- 误导 Samba 版本（报告 4.6.4，实际 4.6.3）
- 模拟 IDS/IPS 警报

### 3. 多个干扰项
- 端口 2222 上的 SSH 蜜罐
- 假管理面板
- SQL 注入但不到达目标
- 文件上传看起来有希望但不是主路径

### 4. 复杂认证
- 不同权限的多个用户账户
- 某些共享需要认证
- 访客访问仅限特定共享

## 💡 攻击者提示

1. **不要相信版本号** - 它们设计用来误导
2. **Web 应用大多是干扰** - 利用起来有趣但不是主路径
3. **专注 Samba** - 那是真正漏洞所在
4. **检查所有共享** - 有些比其他更有趣
5. **寻找配置文件** - 它们可能揭示真实版本
6. **安全仪表板是假的** - 它用来迷惑你

## 🛠️ 技术细节

### Samba 配置
- 不同权限的多个共享
