===================================
  TechCorp 文件共享服务器
  Samba Network Share
===================================

欢迎访问公司内部文件共享系统！

此共享目录用于存储公司重要文档、配置文件和备份数据。

-----------------------------------
访问说明:
-----------------------------------
共享名称: myshare
服务器地址: 192.168.1.10 (内部网络)
协议: SMB/CIFS
端口: 445

Windows 用户:
  在文件管理器地址栏输入: \\192.168.1.10\myshare

Linux 用户:
  smbclient //192.168.1.10/myshare -N

-----------------------------------
目录结构:
-----------------------------------
/documents/  - 公司文档和报告
/backup/     - 系统配置备份
/notes/      - 技术笔记和维护记录
