🔄 Docker 服务架构

filehub_samba       (172.20.0.10)  - 核心漏洞点 ⚠️
  └─ Samba 4.6.3 (CVE-2017-7494)
  └─ Port: 445

filehub_web         (172.20.0.20)  - Web应用
  └─ Apache + PHP 7.4
  └─ Port: 80

filehub_mysql       (172.20.0.30)  - 数据库
  └─ MySQL 5.7
  └─ Port: 3306

filehub_ftp         (172.20.0.40)  - 蜜罐
  └─ Fake vsftpd 2.3.4
  └─ Port: 21

filehub_tomcat      (172.20.0.50)  - 假后台
  └─ Nginx (伪装Tomcat)
  └─ Port: 8080

filehub_monitor     (172.20.0.100) - 监控
  └─ Alpine Linux
  └─ 日志记录

🎓 使用流程

1. 阅读 README.md 或 QUICK_START.md
2. 运行 ./deploy.sh 部署环境
3. 运行 ./test_environment.sh 验证
4. 开始渗透测试
5. 完成后对比 hacking.md
